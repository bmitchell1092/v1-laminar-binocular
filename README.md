# v1-laminar-binocular

A rebuilt analysis pipeline for laminar recordings from macaque V1 during
binocular, monocular and dichoptic grating presentation. It also covers the
flash (evp), darkrest, RF-mapping and orientation-tuning recordings from the
same penetrations.

- **Subjects / data:** monkeys B (RV1, Oct–Dec 2021) and J (LV1, Oct–Dec 2022, seven dual-probe days).
- **Hardware:** Blackrock NSP, 32-channel Plexon probes at 100 µm, MonkeyLogic 2, ViewPixx with a mirror stereoscope.
- **Raw data:** `D:\NEUROPHYS DATA\2021\` (read-only).

## Goals
1. Every penetration can be loaded on its own: an indexed trial table, plus
   LFP, CSD, MUA and sorted units, all on the same NSP clock.
2. QC built in at each step: event-code/trial matching, photodiode timing, channel maps, laminar alignment.
3. Reproducible laminar alignment from spike-phase coupling (Davis et al. 2023), cross-checked against CSD.
4. All pooled analyses are generated by code from the session files. That
   includes the laminar binocular normalization and supersaturation (SSN) paper.
